Kalibrasi Deteksi

Turunkan bila ayunan asli tidak terbaca; naikkan bila gerakan biasa ikut terdeteksi sebagai pukulan.

Tinggi pergelangan tangan (satuan panjang badan, bahu ≈ 1.0) agar ayunan dihitung sebagai servis.

Tetapkan sesuai pemain. Mode otomatis memilih pergelangan tercepat, namun kurang andal pada backhand dua tangan.

Belum ada data.

Nilai mentah untuk keperluan kalibrasi: tinggi puncak, rentang mendatar, arah fase kontak, dan jumlah pembalikan arah.

Catatan metodologis. Klasifikasi ini masih rule-based (analisis lintasan & kecepatan sendi), bukan model machine learning terlatih. Nilai kalibrasi bersifat empiris dan perlu disesuaikan per sudut kamera. Untuk publikasi, sistem ini diposisikan sebagai baseline pembanding terhadap model LSTM/TCN yang dilatih dari dataset berlabel.
